# 📖 Guia Rápido — BolãoCopa 2026

## Para Participantes

### 1. Como participar de um bolão
1. Acesse o link compartilhado pelo organizador (`#/b/nome-do-bolao`)
2. Clique em **"Quero participar"**
3. Preencha seus dados + crie uma conta (usuário + senha)
4. Escolha quantas cotas deseja comprar
5. Faça o pagamento via PIX
6. **Você será redirecionado automaticamente** para seu painel (`/perfil`)

### 2. Como fazer palpites
1. Acesse **Meu Perfil**
2. Escolha o bolão
3. Clique em **"Preencher palpites"**
4. Se comprou mais de 1 cota, selecione o bilhete e preencha os palpites
5. Salve

### 3. Como indicar amigos
1. No seu painel, acesse a aba **"Indicações"**
2. Copie o link do bolão desejado
3. Compartilhe no WhatsApp
4. Se o indicado chegar ao pódio, você ganha **5% do prêmio dele**

## Para Organizadores

### 1. Como criar um bolão
1. Acesse **Área do Organizador** (link no rodapé da home)
2. Faça login ou crie sua conta
3. Clique em **"+ Novo Bolão"**
4. Preencha:
   - Nome do bolão
   - Valor da cota
   - Quantidade total de cotas
   - Data limite
   - Comissão (5-15%)
   - Bônus de indicação (1-10%)
   - Distribuição do prêmio (padrão 50/30/20)
5. Clique em **Criar Bolão**

### 2. Como compartilhar
- No painel do organizador, clique em **"Compartilhar"**
- O link gerado é: `seu-dominio.com/#/b/seu-bolao`
- Este link **não revela** que a plataforma é BolãoCopa

### 3. Como gerenciar
- Acesse **Painel do Organizador**
- Veja participantes, ranking, financeiro e indicações
- Exporte CSV de participantes
